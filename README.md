# CloudVision Custom Dashboards (AQL)

Custom-built dashboards for Arista CloudVision, powered by AQL (Arista Query Language).

## Dashboards

- **Interface Health**: errors, discards, and utilization
- **Device Inventory**: models, EOS versions, and uptime
- **Environment**: temperature, fans, and power

## Usage

1. In CloudVision, open **Dashboards** and add a widget.
2. Set the data source to **AQL**.
3. Paste a query from the `queries/` folder.

## Contributing

Pull requests are welcome. Add your query to `queries/` and list the dashboard above.
